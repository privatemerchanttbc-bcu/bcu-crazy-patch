================================================================================
  BCU CRAZY PATCH
================================================================================

Control your cats yourself, and play two game modes BCU does not have.

Your BCU is not changed. Delete this folder and everything is back to normal.


HOW TO START
------------

1. Put this "BCU Crazy" folder inside your BCU folder - the folder that has
   BCU-0-5-8-8.jar in it.

2. Open "Play BCU with Crazy Patch.bat" instead of starting BCU the usual way.

That is all. You need Java installed, but if BCU already runs on your computer
then you already have it.

A window appears asking which features to turn on. Tick what you want and press
Start BCU. Anything you leave unticked is not loaded at all.


WHAT YOU GET
------------

CRAZY PATCH
   Take the wheel in battle. Steer a cat with the keyboard, aim the sniper
   yourself, and use things the normal game does not have: cats that grow,
   beam weapons, bases you can build and edit, a summoning ritual, cat
   stacking, rebirth on death, and cats that bump into each other instead of
   walking through each other.

ADVENTURE MODE
   A different game. You control one cat in real time - walk, jump, attack -
   through a side-scrolling stage. No cannon, no worker cat, no retreat.

CUSTOM MAP STUDIO
   Draw your own terrain for those modes: ground, water, ice, moving
   platforms, backgrounds and decorations.


IF SOMETHING GOES WRONG
-----------------------

"No BCU jar found"
   This folder is in the wrong place. It has to sit inside your BCU folder,
   right next to the BCU file itself.

Nothing looks different
   Make sure you opened "Play BCU with Crazy Patch.bat" and not BCU itself,
   and that the feature you wanted is ticked.

Custom Map Studio looks empty
   It needs the "Tiles" folder in your BCU folder to have anything to draw
   with.

Anything else
   There is a file called manual-control.log in this folder. Send it along
   with your report.


ABOUT "Install Crazy Patch.bat"
-------------------------------

You do not need it. It just adds a shortcut to your BCU folder so you can
start the game from there instead of coming into this folder. It does not
change BCU either.


WHERE YOUR THINGS ARE SAVED
---------------------------

Adventure saves and your feature choices are kept in this folder, not inside
BCU. Maps you draw are kept in the workspace folder inside BCU.
